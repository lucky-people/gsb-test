请在当前文件夹中从零实现一个可以在浏览器中运行的“实时节奏与反应训练系统”。它不是静态统计页面，而是一个能真实采集键盘/鼠标输入、播放节拍、进行多种测试并给出结果和训练建议的交互工具。请在首轮内独立完成全部工作，不要向我提问或请求确认，也不要等待我输入；遇到不确定的地方按最合理的工程方案自行决定，并在 README 中说明关键取舍。

1. 项目启动
- 在当前文件夹中完成项目，不要新建嵌套项目目录。
- 安装依赖后可以直接启动。
- 执行启动命令后，能够在浏览器中打开系统。
- 启动方式、项目结构和基本使用说明写入 README。
- 使用 Node.js 18+，前端框架不限，但必须是可本地启动的浏览器应用。

2. 基础设置
- 用户可以填写：音频输出延迟、输入延迟补偿、BPM、节拍细分、测试时长、难度、输入设备（键盘或鼠标）和音量。
- 提供恢复默认设置和清空本地数据的功能。
- 设置刷新浏览器后不能无故丢失。
- 支持保存多组训练配置，每组配置有名称，可用于重复相同测试。

3. 延迟校准
- 提供一个校准页面，通过节拍和视觉提示让用户敲击，系统估算音频输出延迟和输入延迟。
- 支持 60 BPM、120 BPM、240 BPM 三档校准。
- 记录每次敲击的时间偏差、平均偏差、标准差和完成时间。
- 校准结果需要能够保存，并用于后续测试的时间补偿。
- 如果浏览器不支持 Web Audio 或必要的输入事件，要显示明确提示并给出替代方案。

4. 节奏跟随测试
- 系统持续播放节拍，用户用键盘或鼠标跟随节拍敲击。
- 节拍间隔和视觉提示要有变化，不能完全固定。
- 记录命中率、平均时间偏差、最快偏差、漏拍次数和连击长度。
- 敲击在错误时间要记录为失误。
- 测试结束后显示节奏稳定性，以及用户更偏向抢拍还是拖拍。

5. 视觉反应测试
- 屏幕上随机出现视觉目标，用户需要尽快点击或按键。
- 目标位置、大小、颜色和出现时间不能完全固定。
- 记录点击成功率、平均反应时间、最快反应时间、漏点次数和误触次数。
- 点击空白区域要记录为失误。
- 测试结束后显示反应速度分布和稳定性。

6. 双任务测试
- 同时进行节奏跟随和视觉反应，用户需要一边跟节拍一边处理随机视觉目标。
- 记录双任务下的节奏偏差、反应时间、命中率和任务切换损失。
- 目标位置和出现顺序每次都要有所变化。
- 测试结束后显示两个任务之间的干扰程度。

7. 持续注意与疲劳测试
- 进行较长时间的连续测试，目标频率逐渐变化，并偶尔出现需要抑制反应的干扰刺激。
- 记录前半段和后半段的命中率、反应时间、偏差、漏点和误触。
- 显示是否出现注意力下降、反应漂移或稳定性下降。
- 不能只看最后总分，要分阶段统计。

8. 训练方案对比
- 用户可以保存多组训练配置。
- 可以使用不同配置重复相同测试。
- 测试时使用相同的目标数量、目标规则和时长。
- 结果页面能够清楚显示不同配置之间的差异。
- 不要只显示一个总分，要说明命中、反应、节奏偏差和持续注意分别有什么变化。

9. 结果页面
- 每次测试结束后显示详细结果：命中率、平均反应时间、最快反应时间、平均时间偏差、标准差、失误次数、漏点次数、持续注意稳定性和综合分数。
- 根据实际测量结果给出简单明确的建议，例如“输入延迟补偿偏低”“节奏稳定性较好”“双任务下反应下降明显”“建议降低目标速度”等。
- 建议必须由实际数据生成，不能使用固定假文字。
- 结果页面要能重新测试、返回设置和保存本次记录。

10. 测试记录
- 保存最近多次测试记录。
- 用户可以查看某一次完整测试结果。
- 支持删除单条记录和清空全部记录。
- 支持将测试结果导出为 JSON 或 CSV 文件。
- 刷新浏览器后，已保存的记录不能丢失。
- 如果本地数据损坏，需要显示清楚的错误提示，并提供恢复或清空选项。

11. 页面和操作
- 页面至少包含：开始页面、设置页面、校准页面、测试选择页面、测试页面、结果页面和记录页面。
- 测试开始前显示倒计时。
- 测试过程中显示剩余时间和当前进度。
- 支持暂停、继续和重新开始。
- 测试过程中不能因为误触页面按钮而丢失当前结果。
- 页面需要适配常见的电脑屏幕尺寸。
- 主要交互应该集中在实时测试中，不要把项目做成单纯的表格或后台页面。

12. 测试和完成标准
- 为时间偏差计算、目标生成、命中判断、反应时间、分数计算、设置保存和测试记录编写基本测试。
- 完成后实际运行测试。
- 在浏览器中实际完成一次校准、一次节奏跟随、一次视觉反应、一次双任务和一次持续注意测试。
- 所有按钮都必须真正可用。
- 不要留下空函数、假数据、无效按钮或明显的 TODO。
- 最后说明修改和新增了哪些文件，以及如何启动项目。

13. 展示与录屏验收
- 应用启动后，先展示开始页和设置页，修改 BPM、难度、时长和输入设备，刷新页面确认设置仍然存在。
- 进入校准页，分别演示 60 BPM 和 120 BPM 校准，展示偏差结果和保存后的补偿值。
- 依次演示节奏跟随、视觉反应、双任务和持续注意各一次，展示倒计时、实时进度、暂停/继续和结果页。
- 在结果页展示命中率、反应时间、偏差、稳定性、综合分数和自动生成的建议。
- 保存两组不同的训练配置，用相同测试规则各跑一次，在结果页对比命中、反应、节奏偏差和持续注意差异。
- 进入记录页，展示历史记录详情、单条删除、全部清空确认，以及 JSON/CSV 导出。
- 刷新页面，确认记录和设置仍然存在。
- 演示一次本地数据损坏时的错误提示，以及恢复或清空路径。
- 录屏要求：从干净状态启动，完整展示真实输出，失败过程也不要剪掉，时长控制在 90 秒以内。
